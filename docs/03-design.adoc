= Design notes
:toc:

== Overview

java-metrics parses Java sources with Eclipse JDT Core and computes structural
metrics at project/file/package/type/member scope. Outputs are deterministic JSON
or text.

== Architecture

- Parser: `JdtParser` builds an `AnalysisContext`.
- Providers: built-in Java metrics and optional CK provider.
- Measurements: `MeasurementStore` with completeness status.
- Aggregation: project-level aggregation with sensitivity bounds.
- Export: `JsonExporter`, `ProjectAggregationExporter`.

== Partial values

`PARTIAL` values are never mixed into primary statistics; they are handled by
separate sensitivity aggregation. Interval results provide safe lower/upper bounds.
