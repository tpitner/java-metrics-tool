== Primary metrics

[cols="1,1,1,1,1,1",options="header"]
|===
| Dimension | Primary metric | Provider | Scope | Unit | specification / incomplete behavior
| Size | `java.physical-loc`, `java.ncloc` | java | project/file/package/type/member | lines | exact; partial as bounds
| Complexity | `ck.wmc` | ck | type | count | exact/interval
| Complexity | `java.cyclo` | java | method | count | planned gap
| Coupling | `ck.cbo` | ck | type | count | exact
| Coupling | `java.ca`, `java.ce` | java | package | count | lower bounds + interval
| Cohesion | `java.lcom4` | java | type | count | exact/upper bound partial
| Inheritance | `ck.dit`, `ck.noc` | ck | type | count | exact
| Martin | `java.instability`, `java.abstractness`, `java.distance` | java | package | ratio | exact/interval/NA
|===

== Control and audit metrics

* `ck.rfc`, `ck.fan-in`, `ck.fan-out`, `ck.methods`, `ck.public-methods`, `ck.fields`
* `java.declared-*`, source-line metrics
* CK TCC/LCC are sensitivity/comparison variants, not primary M3 (unless RQ2 requires).

== Notes

* QMOOD/Li & Henry metrics (NOP, DCC) are not in the primary M3 set unless RQ2 explicitly requires a minimal subset.
* Each new metric follows the same process as LCOM4 and Martin metrics.
