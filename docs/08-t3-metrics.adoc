= Metrics specification
:toc:

== Metric catalog

Built-in metrics are defined in `BuiltInMetricDefinition` and CK metrics in
`CkMetricDefinition`. Each metric has a `MetricId`, scope, unit, and
specification key.

== Aggregation

Primary aggregation uses only `OK` values. `PARTIAL` values are handled by
separate sensitivity aggregation with lower/upper endpoints. Export is
deterministic JSON/CSV with completeness counts.
