Java source-code metrics CLI based on Eclipse JDT Core 3.47.0.

== Requirements

Building and running `java-metrics` requires Java 21 LTS or later. Maven is
required to build the tool and to analyse a Maven project via `--pom`; it is not
required when running the packaged JAR against explicitly supplied Java source
files or directories.

The runtime used to execute `java-metrics` is independent of the source level
selected for the analysed project with `--release`.

== Supported metrics

The built-in provider computes declared method, constructor, and field counts;
physical LOC and NCLOC; type-exclusive physical LOC and NCLOC; type-level
LCOM4; and the package-level `Ca`, `Ce`, instability, abstractness, and distance
metrics.

The optional CK provider imports its frozen set of type- and member-level size,
complexity, coupling, cohesion, and inheritance metrics. The exact JORS 1.1.0
scope, metric scopes, and known limitations are documented in
`docs/jors-release-scope.adoc`.

== Install

Each GitHub release contains a self-contained executable JAR, its SHA-256
checksum, `LICENSE`, and `NOTICE`. Download all four files from the release page
and verify the JAR before running it.

On Linux or macOS:

[source,bash]
----
shasum -a 256 -c java-metrics-<version>.jar.sha256
java -jar java-metrics-<version>.jar --help
----

On Windows PowerShell, compare the published checksum with:

[source,powershell]
----
Get-FileHash .\java-metrics-<version>.jar -Algorithm SHA256
java -jar .\java-metrics-<version>.jar --help
----

Java 21 or later is required; Maven is not required for this installation.

== Build and run from source

Clone a specific release tag when reproducing a published version:

[source,bash]
----
git clone --branch v<version> --depth 1 \
  https://github.com/tpitner/java-metrics-tool.git
cd java-metrics-tool
----

Build:

[source,bash]
----
mvn -q package
----

Single file:

[source,bash]
----
java -jar target/java-metrics-1.0-SNAPSHOT.jar path/to/File.java
----

Directory or module (recursive):

[source,bash]
----
java -jar target/java-metrics-1.0-SNAPSHOT.jar path/to/directory
----

Maven project:

[source,bash]
----
java -jar target/java-metrics-1.0-SNAPSHOT.jar --pom pom.xml
----

For a complete minimal input, configuration, expected output, and verification
command, see `examples/quickstart/README.adoc`.

=== Output formats

The CLI supports `text`, deterministic `json`, and the ANSI-coloured `preview`
format. It does not support `--format csv`. Project aggregation and its JSON/CSV
serializers currently exist as a programmatic API and are not wired into the
command-line interface.

== CK dependency (optional)

java-metrics can use the CK tool. Clone and build it first:

[source,bash]
----
git clone https://github.com/mauricioaniche/ck.git ../ck
cd ../ck
git checkout 8a1ef91
mvn -DskipTests package
----

The adapter contract is frozen to CK revision `8a1ef91`. Using a different CK
revision may fail when its CSV schema differs from the expected schema.

Then point java-metrics to the CK jar:

[source,toml]
----
[providers.ck]
enabled = true
jar = "../ck/target/ck-0.7.1-SNAPSHOT-jar-with-dependencies.jar"
----
