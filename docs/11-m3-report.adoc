= M3 report
:toc:

== Included metrics

See `09-m3-metric-set.adoc`. Primary: size, complexity (`ck.wmc`), coupling
(`ck.cbo`, `java.ca/ce`), cohesion (`java.lcom4`), inheritance (`ck.dit`,
`ck.noc`), and Martin (`java.instability`, `java.abstractness`,
`java.distance`). Built-in cyclomatic complexity remains a planned gap and is
not published by the Java provider.

== Excluded metrics

QMOOD/Li & Henry (NOP, DCC) are not in M3 unless RQ2 explicitly requires.

== Validation

* `ValidationCorpusTest` and `ProjectMetricAggregatorTest` pass.
* Differential testing with external tools is limited to CK; other providers are not
  part of M3.

== Limitations

* Method-level `java.cyclo` and additional complexity metrics such as nesting
  depth are not implemented in M3.
* Project aggregation export is deterministic JSON/CSV through the
  programmatic `ProjectAggregationExporter` API. It is not exposed as a CLI
  output mode.
